# Nexus AI Chat 🤖

Nexus AI is a modern, user-friendly AI chat application built for Android, leveraging the capabilities of Google's Gemini API.

## 🚀 Features

* 💬 **AI Conversational Chat:** Interact with AI in natural language to get instant answers and solutions.
* 🖼️ **Image Analysis & Generation:** Understand context from uploaded images and generate custom visual art from text prompts.
* ⚡ **Sleek & Fast UI:** Optimized native Android user interface for a smooth experience.

## 🛠️ Tech Stack

* **Language:** Kotlin (100%)
* **Platform:** Android SDK
* **AI Engine:** Google Gemini API / Google AI Studio
